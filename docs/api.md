# API 仕様書

## 概要

- **ベースURL**: `http://localhost:8080`
- **データ形式**: JSON (`Content-Type: application/json`)
- **認証**: なし

---

## エンドポイント一覧

| メソッド | パス               | 概要                       |
| -------- | ------------------ | -------------------------- |
| `GET`    | `/ping`            | ヘルスチェック             |
| `POST`   | `/solo`            | ゲーム開始（ヒント生成）   |
| `POST`   | `/solo/:id/answer` | 回答を送信して正誤判定     |
| `GET`    | `/solo/:id/answer` | 正解を取得（ギブアップ）   |
| `GET`    | `/solo/board/:id`  | 終了済みラウンドの詳細取得 |

---

## ゲームの流れ

```
1. POST /solo                    ゲーム開始 → id と hints を受け取る
          │
          ▼
2. POST /solo/:id/answer         ヒントを見ながら回答を送信
   ├── isCorrect: true  → 正解！ラウンド終了
   └── isCorrect: false → 不正解。何度でも再挑戦可能
          │
          ▼  （諦める場合）
3. GET /solo/:id/answer          ギブアップ → 正解を表示、ラウンド終了
          │
          ▼
4. GET /solo/board/:id           終了後のラウンド詳細を取得（結果画面用）
```

---

## 共通エラー形式

すべてのエラーレスポンスは同じ形式です。

```json
{
  "error": "エラーメッセージ"
}
```

| ステータス | 意味                                                     |
| ---------- | -------------------------------------------------------- |
| `400`      | リクエスト不正（IDの形式エラー、バリデーションエラー等） |
| `404`      | 指定したラウンドが存在しない                             |
| `500`      | サーバー内部エラー                                       |

## エンドポイント詳細

### `GET /ping`

ヘルスチェック用。サーバーが起動しているか確認できます。

#### レスポンス `200`

```json
{
  "message": "pong"
}
```

---

### `POST /solo`

新しいゲームラウンドを開始します。AIが生成した10個のヒントが返ります。

#### リクエスト

ボディ不要。

#### レスポンス `200`

```json
{
  "result": {
    "id": 1,
    "hints": [
      "ヒント1（京都風）",
      "ヒント2（大阪風）",
      "ヒント3（京都風）",
      "ヒント4（大阪風）",
      "ヒント5（京都風）",
      "ヒント6（大阪風）",
      "ヒント7（京都風）",
      "ヒント8（大阪風）",
      "ヒント9（京都風）",
      "ヒント10（大阪風）"
    ]
  }
}
```

| フィールド     | 型         | 説明                                                                                                   |
| -------------- | ---------- | ------------------------------------------------------------------------------------------------------ |
| `result.id`    | `number`   | ラウンドID。以降のAPIで使用する                                                                        |
| `result.hints` | `string[]` | 10個のヒント。奇数番目(index 0,2,4...)が京都風、偶数番目(index 1,3,5...)が大阪風。後半ほど正解しやすい |

#### エラー

| ステータス | `error`                  | 原因                                           |
| ---------- | ------------------------ | ---------------------------------------------- |
| `500`      | `"Failed to start game"` | サーバー側の問題（AI生成失敗、DB保存失敗など） |

#### フロント実装例

```typescript
const res = await fetch("http://localhost:8080/solo", { method: "POST" });
const data = await res.json();
// data.result.id   → ラウンドID（保持しておく）
// data.result.hints → ヒント配列（1つずつ表示していく）
```

### `POST /solo/:id/answer`

ユーザーの回答を送信して正誤を判定します。正解ならラウンドが自動で終了します。

#### リクエスト

**パスパラメータ**

| 名前 | 型       | 説明       |
| ---- | -------- | ---------- |
| `id` | `number` | ラウンドID |

**ボディ**

```json
{
  "answer": "ユーザーの回答"
}
```

| フィールド | 型       | 必須 | 説明                   |
| ---------- | -------- | ---- | ---------------------- |
| `answer`   | `string` | Yes  | ユーザーの回答テキスト |

> **判定ルール**
>
> - 大文字・小文字を区別しない（`Takoyaki` = `takoyaki`）
> - 前後の空白は無視される
> - バックエンド側で複数の正解パターンが登録されており、いずれかに一致すれば正解

#### レスポンス `200`

```json
{
  "isCorrect": true
}
```

| フィールド  | 型        | 説明                           |
| ----------- | --------- | ------------------------------ |
| `isCorrect` | `boolean` | `true`: 正解 / `false`: 不正解 |

#### エラー

| ステータス | `error`                                  | 原因                                |
| ---------- | ---------------------------------------- | ----------------------------------- |
| `400`      | `"Invalid ID"`                           | IDが数値でない                      |
| `400`      | `"Key: 'CheckAnswerRequest.Answer' ..."` | `answer` フィールドが空または未送信 |
| `404`      | `"round not found: id=1"`                | 指定IDのラウンドが存在しない        |
| `500`      | `"Failed to check answer"`               | サーバー内部エラー                  |

#### フロント実装例

```typescript
const res = await fetch(`http://localhost:8080/solo/${roundId}/answer`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ answer: userInput }),
});
const data = await res.json();
// data.isCorrect → true なら正解画面へ、false なら再挑戦
```

### `GET /solo/:id/answer`

ギブアップ時に正解を取得します。呼んだ時点でラウンドが自動的に終了します。

#### リクエスト

**パスパラメータ**

| 名前 | 型       | 説明       |
| ---- | -------- | ---------- |
| `id` | `number` | ラウンドID |

#### レスポンス `200`

```json
{
  "answer": "たこ焼き"
}
```

| フィールド | 型       | 説明         |
| ---------- | -------- | ------------ |
| `answer`   | `string` | 正解テキスト |

#### エラー

| ステータス | `error`                   | 原因                         |
| ---------- | ------------------------- | ---------------------------- |
| `400`      | `"Invalid ID"`            | IDが数値でない               |
| `404`      | `"round not found: id=1"` | 指定IDのラウンドが存在しない |
| `500`      | `"Failed to get answer"`  | サーバー内部エラー           |

#### フロント実装例

```typescript
const res = await fetch(`http://localhost:8080/solo/${roundId}/answer`);
const data = await res.json();
// data.answer → 正解を表示
```

---

### `GET /solo/board/:id`

終了済みラウンドの詳細を取得します。結果画面やシェア機能で使えます。

**注意**: ラウンドが終了していない（正解もギブアップもしていない）場合は `400` エラーになります。

#### リクエスト

**パスパラメータ**

| 名前 | 型       | 説明       |
| ---- | -------- | ---------- |
| `id` | `number` | ラウンドID |

#### レスポンス `200`

```json
{
  "round": {
    "id": 1,
    "answer": "たこ焼き",
    "hints": [
      "ヒント1",
      "ヒント2",
      "ヒント3",
      "ヒント4",
      "ヒント5",
      "ヒント6",
      "ヒント7",
      "ヒント8",
      "ヒント9",
      "ヒント10"
    ],
    "updated_at": "2026-02-19T15:04:05+09:00"
  }
}
```

| フィールド         | 型         | 説明                                  |
| ------------------ | ---------- | ------------------------------------- |
| `round.id`         | `number`   | ラウンドID                            |
| `round.answer`     | `string`   | 正解                                  |
| `round.hints`      | `string[]` | 10個のヒント                          |
| `round.updated_at` | `string`   | 最終更新日時（ISO 8601 / Asia/Tokyo） |

#### エラー

| ステータス | `error`                             | 原因                         |
| ---------- | ----------------------------------- | ---------------------------- |
| `400`      | `"Invalid ID"`                      | IDが数値でない               |
| `400`      | `"round is not finished yet: id=1"` | まだラウンドが終了していない |
| `404`      | `"round not found: id=1"`           | 指定IDのラウンドが存在しない |
| `500`      | `"Failed to get round"`             | サーバー内部エラー           |

#### フロント実装例

```typescript
const res = await fetch(`http://localhost:8080/solo/board/${roundId}`);
const data = await res.json();
// data.round.answer     → 正解
// data.round.hints      → ヒント一覧
// data.round.updated_at → プレイ日時
```
